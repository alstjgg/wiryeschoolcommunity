# 위례인생학교 업무 도우미 — E2E 테스트 체크리스트

> 실제 데이터로 전체 플로우를 검증한다.

---

## 준비물

- [ ] 실제 `LEARNING_APPLY*.xls` (배움숲 다운로드)
- [ ] 실제 은행 입금내역 엑셀
- [ ] 테스트용 회차 폴더가 Google Drive에 존재하는지 확인 (`02 학사운영/연도/회차 폴더`)
- [ ] 신규가입/정회원 신청서 파일이 올바른 폴더에 있는지 확인 (파일명에 연도 포함 여부)
- [ ] 회원관리 시트 3탭(회원목록/회원기록/수강기록) 헤더 행 입력 여부 확인
- [ ] 회원목록 탭에 `예외여부` 컬럼 존재 여부 + 강사/사무처 직원 행 `TRUE` 입력 여부 확인
- [ ] 출석 체크 테스트용 종이 출석부 사진 (또는 테스트 이미지)

## 8. 데이터 무결성 검증

회차 전체 워크플로우(입금대조 → 출석부 생성 → 출석 체크 → 종강 처리)를 한 번 완전히 돌린 후 확인.

| # | 확인 항목 | 확인 |
|---|---------|------|
| 8-1 | 회원목록 탭: 이번 회차 수강생 등급이 준회원으로 올바르게 변경됨 | ☐ |
| 8-2 | 회원기록 탭: 입금 대조 시 등급 변경 이력 기록됨 (신규가입/수강료입금/정회원비입금) | ☐ |
| 8-3 | 회원기록 탭: 종강 처리 시 등급 강등 이력 기록됨 (종강강등/겨울학기강등) | ☐ |
