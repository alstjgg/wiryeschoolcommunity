# 위례인생학교 업무 도우미 — E2E 테스트 체크리스트

> 실제 데이터로 전체 플로우를 검증한다. 테스트 전 준비물을 확인할 것.

---

## 준비물

- [ ] 실제 `LEARNING_APPLY*.xls` (배움숲 다운로드)
- [ ] 실제 은행 입금내역 엑셀
- [ ] 테스트용 회차 폴더가 Google Drive에 존재하는지 확인 (`02 학사운영/연도/회차 폴더`)
- [ ] 신규가입/정회원 신청서 파일이 Drive에 있는지 확인 (파일명에 회차 문자열 포함 여부)
- [ ] 회원관리 시트에 테스트 데이터 존재 여부 확인

---

## 1. 진입 및 회차 확인

| # | 시나리오 | 예상 결과 | 확인 |
|---|---------|---------|------|
| 1-1 | 💰 입금 대조 버튼 클릭 | 현재 날짜 기준 회차명 + 확인 버튼 3개 표시 | ☐ |
| 1-2 | "✅ 맞습니다" 클릭 | 신청자 목록 업로드 요청으로 진행 | ☐ |
| 1-3 | "📅 다른 회차에요" 클릭 | "어떤 회차인지 알려주세요" 메시지 | ☐ |
| 1-4 | 다른 회차 텍스트 입력 (`봄학기`, `2026-2` 등) | 올바르게 파싱되어 재확인 메시지 표시 | ☐ |
| 1-5 | 알 수 없는 텍스트 입력 (`아무말`) | "인식하지 못했어요" 재안내 | ☐ |
| 1-6 | "❌ 취소" 클릭 | 취소 메시지 + 기본 버튼 5개 표시 | ☐ |
| 1-7 | 자유 텍스트로 진입 (`입금대조 시작해줘`) | LLM 의도 분류 → 확인 메시지 → 워크플로우 진입 | ☐ |
| 1-8 | 자유 텍스트 질문 (`입금 대조가 뭐야?`) | Q&A 답변 후 기본 버튼 표시 (워크플로우 진입 안 함) | ☐ |
